# Hero Academy 🦸

Lern-App für Grundschüler (Klasse 1–4): Mathe, Deutsch, Englisch. Duolingo-artiger Lernpfad, Sammelkarten als Belohnung,
Vorbereitung auf Klassenarbeiten. Läuft komplett im Browser, offline, ohne Server – installierbar auf dem iPad.

## Ausprobieren
```bash
npm start        # http://localhost:8080
npm test
```
Auf dem iPad: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

## Veröffentlichen (GitHub Pages, kostenlos)
Repo → Settings → Pages → Source: **GitHub Actions**. Jeder Push auf `main` testet und veröffentlicht.
Adresse danach: `https://<benutzer>.github.io/<repo>/`
